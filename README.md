# Battle Move Info

A [gen1recomp](https://github.com/bryanthaboi/gen1recomp) mod that shows type matchup markers on the battle move-select TYPE box.

**Requires** gen1recomp `>=0.1.37 <2.0.0`. Declares `engine_internals`.

## Markers

| Marker | Meaning |
| --- | --- |
| `!` | Super effective |
| `!!` | 4x |
| `.` | Normal |
| `-` | Not very effective |
| `--` | 1/4x |
| `xx` | No effect |

## Controls

| Input | Action |
| --- | --- |
| **Up / Down** | Change move |
| **Left / Right** | TYPE / effectiveness / power pages |

On the stats screen moves page during battle, each move also shows a marker vs the current foe.

## Options

**MOVE INFO** ON/OFF

## Install

1. Download `BATTLE_MOVE_INFO-1.0.5.zip` from [Releases](https://github.com/masterwebx/gen1recomp-battle-move-info/releases).
2. In gen1recomp, open **MODS** and **Import mod.zip**.
3. Enable **Battle Move Info** (allow `engine_internals` if prompted).
